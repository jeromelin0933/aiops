\# 4\. Log Generator 設計

目的：

模擬金融系統 Application Logs。

輸出：

logs/aiops.json.log

格式：

JSON Line

主要 Schema：

| 欄位 | 說明 |  
|------|------|  
| timestamp | 發生時間 |  
| service\_name | 微服務名稱 |  
| trace\_id | 分散式追蹤碼 |  
| status\_code | HTTP Status |  
| duration\_ms | 回應時間 |  
| error\_type | 錯誤類型 |  
| error\_message | 錯誤訊息 |  
| source\_ip | Client IP |  
| user\_id | 使用者 |  
| transaction\_id | 交易編號 |  
| downstream\_service | 下游服務 |  
| external\_service | 外部服務 |  
| memory\_usage\_pct | Memory資訊 |  
| rate\_limit\_quota | Rate Limit |

設計理由：

\- 後續 Isolation Forest Feature 使用  
\- Alert Correlation 使用  
\- RCA 使用

\# 6\. Scenario Mapping

共六種金融情境。

| Scenario | 說明 | Log | Metrics |  
|-----------|------|------|----------|  
| S1 | 密碼爆破 | 401、帳號鎖定 | 無 |  
| S2 | DB慢查詢 | ConnectionTimeout、504 | DB Latency ↑ |  
| S3 | OOM | OutOfMemory | Memory ↑ |  
| S4 | 第三方API失敗 | External Timeout | 可擴充 |  
| S5 | DB Network Failure | Connection Refused | 可擴充 |  
| S6 | Rate Limit | 429 | QPS ↑ |

\# 9\. 啟動流程（Deployment Guide）

\#\# Step 1

於專案根目錄執行：

docker compose up \-d

確認：

docker compose ps

應看到：

\- aiops-prometheus  
\- aiops-loki  
\- aiops-promtail  
\- aiops-grafana

皆為 Up。

\---

\#\# Step 2

開啟第二個 Terminal。

啟動 Metrics Generator：

python src/metrics\_generator/metrics\_generator.py

若成功應看到：

🟢 \[Metrics\] Prometheus Exporter 已啟動於 Port 8000

\---

\#\# Step 3

開啟第三個 Terminal。

啟動 Log Generator：

python src/log\_generator/log\_generator.py

若成功應看到：

🟢 \[Logs\] JSON 寫入引擎啟動

並自動建立：

logs/

└── aiops.json.log

\---

\#\# Step 4

開啟瀏覽器：

http://localhost:3000

Grafana 已啟動。

Data Source：

Prometheus：

http://prometheus:9090

Loki：

http://loki:3100

Dashboard：

匯入：

docker/grafana/dashboard.json

json檔import後，畫面會各自異常，就各自點右上角三點點進入edit：  
上三個(metrics)切bulder再切回去code，再run queue，再apply  
底下(logs)自己手選loki，再run queue，再apply

\---

\#\# Step 5

開始測試 Scenario。

例如：

Metrics Terminal

輸入：

2

代表：

DB Latency

Log Terminal

輸入：

2

代表：

DB Timeout

Grafana 即可觀察：

Metrics Latency

Logs

同步變化。
